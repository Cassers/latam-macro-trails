# Latam Macro Trails — PIB vs Riesgo País

Visualización interactiva (D3.js v7 + Tailwind) que traza la trayectoria del PIB
frente al riesgo país para economías de Latinoamérica.

**Ver online:** https://cassers.github.io/latam-macro-trails/

## Stack
- [D3.js v7](https://d3js.org/) — visualización de datos
- [Tailwind CSS](https://tailwindcss.com/) (CDN) — estilos

## Uso local
Abrí `index.html` en cualquier navegador moderno. No requiere build ni servidor.
